The workspace commands.

Inside the app, Vivary sets up and operates workspaces with a small set of commands. They are a part of Vivary.

vivary, create-vivary, tropo, strato, ozone, exo. The same commands are published as packages, so a terminal can use them without the app. A typed knowledge graph, one visible state surface, review with human gates, and coordination for many agents.

Vivary is in development, Windows first, and not released. This site goes live with the app. The workspace commands inside it ship today.

Adoption
Adopting an existing project starts with a dry run. It adds at most three files and asks for approval against an exact hash before writing.
Doctor
Doctor checks the contract and the privacy boundary without touching your files.
Capsule and receipt
The agent gets a bounded capsule of context, and a receipt records what it saw.
Local
No account, no cloud control plane, no telemetry from the workspace. Files stay on your machine.

Four commands, named for the sky.

A vivary contains its own atmosphere. The commands are its layers, from the ground up.

tropo
A typed knowledge graph of what the workspace knows and what depends on what.
strato
One visible state surface, private boundaries, and a loop that only grows when work earns it.
ozone
Graph-aware review and human gates for changes that are durable, destructive, or public.
exo
Claims, conflicts, and role contracts for the moment one agent becomes many.

Use them from a terminal today.

One command creates a workspace. The version is pinned to the last release with a recorded installation proof.

with uv
uvx --from create-vivary==0.4.2 create-vivary init my-workspace --preset coding --no-wizard
with npm
npx @vivary/create@0.4.2 init my-workspace --preset coding --no-wizard
